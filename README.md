# Bike Balancing Control — 单车定向自平衡控制算法

> 全国大学生智能汽车竞赛 ｜ 单车定向组 ｜ STM32

本项目面向全国大学生智能汽车竞赛**单车定向组**，提供基于STM32的自行车自平衡控制算法实现[reference:30]。单车定向组的核心挑战在于：仅有两个轮子的车模需要在保持自身平衡的同时，完成直线冲刺、八字绕桩、颠簸路面穿越等高难度动作[reference:31]。本项目采用**PD控制器 + 几何模型映射**的平衡方案，通过舵机控制车把转向产生离心力来实现车身平衡[reference:33]。

## 🎯 赛题覆盖

| 科目 | 要求 | 技术重点 |
|------|------|----------|
| 直线竞速 | 15~30米直线往返 | 高速稳定性 |

| 颠簸路段 | 坡道、草地、锥桶 | 鲁棒性 |

## ⚙️ 控制算法

### 核心原理

单车平衡的本质是利用舵机控制车把转向产生的**离心力**形成扶正力矩。物理模型可视为一个**倒立摆**：车身往哪边倾倒，舵机就控制前轮向哪边转动[reference:45]。

### 控制架构
IMU传感器(陀螺仪) → 姿态解算(EKF) → PD控制器 → 几何映射 → 舵机角度

text

### 关键方程

**横向加速度需求**：
a_x = KP × θ_error - KD × θ_dot

text
其中 θ_error 为目标倾角与实际倾角的偏差，θ_dot 为倾角角速度（阻尼项）[reference:48]。

**舵机角度映射**：
δ = arctan( L / Lm × tan( arcsin( -a_x × Lm / V² ) ) )

text
其中 δ 为舵机角度，L 为轴距，Lm 为重心到后轮轴心距离，V 为前进速度[reference:49]。

## 🚀 快速开始

### 1. 环境准备
- STM32CubeMX + Keil MDK 或 IAR
- ST-Link调试器

### 2. 硬件连接
- 陀螺仪（I2C/SPI）→ 姿态数据[reference:52]
- 编码器（定时器编码器模式）→ 速度反馈[reference:53]
- 舵机（PWM）→ 转向控制[reference:54]

### 3. 参数调优
- 先调平衡PD参数（KP、KD）[reference:55]
- 再调速度闭环参数
- 不同场地需微调参数以适应摩擦系数变化[reference:56]

### 4. 赛道测试
- 从直线往返开始，逐步增加难度
- 若出现持续偏向一边，检查 `angle_core_deg` 重心偏置角[reference:57]
